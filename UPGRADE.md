# Application Migration Guides

Migration instructions are grouped in the
[PhalconKit migration directory](https://github.com/phalcon-kit/core/tree/master/guides/migrations)
and published in the [documentation](https://phalcon-kit.github.io/docs/guides/migrations/).

- [App layout changes](https://phalcon-kit.github.io/docs/guides/migrations/app-2/)
- [App 4 changes](https://phalcon-kit.github.io/docs/guides/migrations/app-4/)
- [Core 4 changes](https://phalcon-kit.github.io/docs/guides/migrations/core-4/)
- [Package/namespace changes](https://phalcon-kit.github.io/docs/guides/migrations/from-zemit/)
- [Older REST resource changes](https://phalcon-kit.github.io/docs/guides/migrations/rest-0x/)

Each guide states its starting point, preparation, changes, verification, and
rollback steps. For a new application, follow the [README](README.md).
